ABOUT THE PROJECT

How TruthLens works

This project uses a simple Natural Language Processing pipeline that is easy to understand and explain in a school viva.

Model pipeline

  1. Dataset: labelled real and fake news articles.
  2. Preprocessing: lowercasing, URL removal and basic character cleaning.
  3. TF-IDF: converts text into numerical features based on word importance.
  4. Logistic Regression: learns the relationship between those features and the labels.
  5. Flask: provides the website interface for making predictions.

Important: a classifier can make mistakes and can be affected by changes in news style or topics. A prediction should not be treated as proof that a story is true or false.
